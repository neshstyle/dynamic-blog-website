# Dynamic Blog Website

A multi-page blog with full CRUD functionality built with HTML, CSS and JavaScript. Posts are stored in localStorage.

Built for CPAN-134 and Professor Dori. at Humber College 2026.

## Features
- Create, read, update and delete blog posts
- localStorage persistence
- Responsive design for mobile, tablet and desktop
- Multi-branch Git workflow

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
